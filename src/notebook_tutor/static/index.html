    Guided walkthrough

    Learn from a notebook your lecturer prepared.

    You
    Run the cells in order with the ▶ button beside each one. Change the code and run it again whenever you like.
    The tutor
    Explains every cell under it after it runs. Every few cells it asks a question: multiple choice, a short answer, or a change to try in the code and explain. Some outputs stay hidden until you predict them.
    Use it
    Before a session to prepare, or after it to revise.

    Practice

    Write the missing code yourself.

    You
    Complete the cells headed Exercise, then run them. The other cells set things up and run without comments.
    The tutor
    Checks your Python and your data-science reasoning after each run. Gives hints when you ask, from a nudge (1) to a worked solution (3). Suggests an experiment when you get one right.
    Use it
    After a session, to practise on your own.

    In both modes you can ask the tutor anything, explain any cell or text, and see your progress at the top.

    Clear the tutor's notes?

    This removes every explanation, answer and follow-up, every checkpoint and Quiz me question, and the conversation in Ask the tutor, so you can work through the notebook again from scratch. Your lecturer's questions and the output predictions are asked again when you run those cells.

    About Notebook Tutor

    A teaching assistant for Jupyter notebooks: run the code, and understand the ideas behind it.

    What runs

    Python 3.12 in the browser, with NumPy, pandas, Matplotlib, seaborn, SciPy and scikit-learn. No internet from Python, no !pip, no input(), and no Google Drive mounting. Opened in Claude, the tutor uses Claude on each student's own account and asks them to allow it first. In the VS Code extension it uses Gemini, through each student's API key or a course server.

    Your data

    Questions you answer and code you write stay in this browser.

    Preparing notebooks

    Any Jupyter or Colab .ipynb works as it is. Lecturers can mark exercise cells, add their own checkpoint questions, predictions and experiments, and give each exercise a plan from question to code: Preparing notebooks for the tutor.
